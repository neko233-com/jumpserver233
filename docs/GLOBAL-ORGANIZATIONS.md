# 全局组织汇总

> 中文 | [English](./GLOBAL-ORGANIZATIONS.en.md)

E08 的跨组织汇总、中英 Web、CLI/SDK 及用例已编写，**未运行验证**。既有[组织隔离](./ORGANIZATIONS.md)与新增[目录组织映射](./IDENTITY-SOURCES.md)共同组成此组实现；生产多组织故障演练仍待统一验收与实际环境证据。

## 权限与入口

全局只读权限为 `organizations.overview`，可以独立委托；管理员默认具有。组织角色目录排除此权限，组织内管理员、审计员以及组织管理/报表导出权限不能单独取得全局汇总。保存角色的既有修订、审计、撤销语义保持有效。权限授予意味着可读取全部组织的名称、启用/归档状态、活跃成员关系数及聚合资源计数；不授予其中资产操作权限。

Web 为“全局组织汇总”，路由 `/console/organization-overview`。`GET /api/v1/organizations/overview?include_archived=false` 返回汇总；SDK 为 `OrganizationOverview(ctx, includeArchived)`，CLI 为 `jms reports organizations [--include-archived]`。重复请求只读，无新增后台任务、业务数据或发送动作。响应 `private, no-store`；返回前重新认证当前凭据并核对全局权限，撤权或身份代次变化会拒绝返回。

接口属于平台范围，合法 `X-JMS-ORG` 不改变汇总范围；非法/重复头仍按原规则拒绝，不支持 GLOBAL/SYSTEM 虚拟组织。没有改变既有资源路径的组织隔离、四类 REST 认证、WebSocket 帧和录像格式。

## 计数口径与性能

每组织提供主资产、SSH 资产、协议分布、缓存监控在线/离线/未知、节点、用户组、活动终端/桌面票据和运行中作业。子账号不重复计入资产数；过期或未取得的监控没有主动刷新，非 online/offline 状态计作未知。会话计数包含尚未附着及正在关闭的票据，不等于当前真人连接数；SFTP 访问能力与数据库查询不混入此项。

成员数只统计当前可用平台身份；同一身份加入多个组织时分别计数。默认组织保留隐式成员，显式 `none` 排除优先；目录管理关系保留人工覆盖。归档/停用组织的成员元数据可显示，资源计数为 null，不加入资源总计。全部成员关系数与资源总计具有不同口径。

采集只读取已经初始化的运行服务与已有监控缓存，不探测 SSH、不解密远端凭据、不打开停用组织，也不因查看而启动新组织。刚创建但尚未初始化的启用组织、关闭或读取失败显示 unavailable/null，`partial=true`；总计仅包含成功采集的组织，并报告 collected/enabled 数量。成员、库存与活动值是请求期间的观测，不是跨存储原子快照或完整历史仓库。

最多沿用现有 100 个组织，单实例最多四个并发汇总请求，每次上下文预算 15 秒。原生库存统计仅复制主资产 ID/协议后读取状态计数，避免构造完整资产/轮换/凭据响应；不持久化额外汇总副本或引入依赖。Web 使用手动刷新、最多 100 行的本地名称筛选和可横向滚动的表格，撤权/刷新失败清除旧结果，不持续轮询。
