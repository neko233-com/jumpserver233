# 项目 UI 设计与 oil-ui

> 中文 | [English](./UI-DESIGN.en.md)

## 安装与来源

按用户要求，将 [oil-oil/dsh-oil-ui](https://github.com/oil-oil/dsh-oil-ui) 内附的 `skills/oil-ui` 安装到 `.agents/skills/oil-ui/`，供本项目使用。固定上游 commit `b67ae2df6c2c9d65e177aaa1ce703e65457b24d7`，技能声明版本 `0.23.8`。来源和逐文件 SHA-256 记录在 `.agents/skills/oil-ui.source.json`；保留上游 `LICENSE`、字体许可和原文。

使用 `skill-installer` 的 `install-skill-from-github.py`，参数为 `--repo oil-oil/dsh-oil-ui --path skills/oil-ui --ref b67ae2df6c2c9d65e177aaa1ce703e65457b24d7 --dest <项目>/.agents/skills --method download`。没有修改全局技能目录，没有安装 DeepSeek Harness 插件或 npm 运行依赖。下轮会话可发现项目技能，本轮已直接读取并应用其规范。

`dsh-oil-ui` 的原生 `oil_ui_*` 工具属于 DeepSeek Harness；在 Codex 中用现有文件、浏览器和看图工具执行对应步骤，不假称这些工具存在。不自动更新技能，不启动付费服务、素材抓取或推荐脚本。第三方字体、图片及工具源码不进入网页依赖；`.agents/` 从 Docker context 排除。

## 控制台方向

**让运维人员先找到主机，再完成连接、检查或授权操作。** 沿用用户提供的暗色 SSH 管理参考和现有品牌，采用紧凑、安静、可长期阅读的工具界面。真实资产和监控值是主要内容，不新增营销区块、装饰图、外部字体或动效库。

- mini 默认导航与产物聚焦主机、监控、轮换、Agent/登录审计、用户/角色、访问策略与系统维护。云同步、AI、复杂身份等 17 个页面不进入路由和构建图，原源码、后端权限/接口及数据保留；报表和低频本地控制收进“更多功能”。搜索只查找当前产品页面，不显示失效入口。
- 搜索仅过滤当前可见页面；空结果可清除并恢复焦点。导航搜索不是全站数据搜索。标签跟随当前语言，切换语言无需刷新。
- 宽屏保留可独立滚动的侧栏；760px 及以下使用原生按钮展开导航，选中页面后收起，将空间留给资产与正文。Esc 先清空搜索，再关闭菜单并回到触发按钮。
- 提供跳转正文入口、可见键盘焦点、当前页标记和搜索结果播报。长菜单名称可换行。品牌颜色仍由既有配置提供。
- 资产表格正文提升到 13px，地址和监控值使用等宽数字。Playbook 编辑器沿用品牌变量，源码保持等宽字体。
- 高频操作只做 120ms 颜色反馈；尊重 `prefers-reduced-motion`。不增加阻塞操作的入场动画、轮询或渲染依赖。保留现有业务说明，未删减审计和权限依据。

## 验证边界

生产浏览器 **55/55** 通过。修复后的控制台通过 **1600/1440/1280/900/715/375px × 中英双语**，覆盖真实夹具监控、表内操作按钮、桌面行高 ≤128px、搜索/清除/Esc/焦点、当前页与移动导航。专项保留两张截图，已目视检查中文桌面截图；另用内置浏览器独立核对中英主机列表和真实 SSH 夹具的 CPU/内存/网络/磁盘。

1001–1600px 侧栏为 176px，监控压成四行且操作可见。原生浏览器还验证目录输入的可访问名称及中英桌面/移动执行表单。这里只声明功能及实际渲染验收，不编造视觉评分。源码与报告见 [mini 验收报告](./MINI-ACCEPTANCE.md)。

Linux Chromium 的默认锚点聚焦存在不稳定表现，已改为显式聚焦正文并关闭移动导航；新增重复键盘激活检查。专项复验通过，15.0s。
