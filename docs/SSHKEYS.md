# SSH 私钥凭据

> 中文 | [English](./SSHKEYS.en.md)

SSH 密钥安装、验证后轮换、显式启用的七天计划及持久化阶段恢复见 [SSH 密钥轮换](./SSH-KEY-ROTATION.md)。

资产与网关均可使用服务端保管的 SSH 私钥。管理员导入密钥，操作者使用原有目标资产授权进入 Web SSH、CLI、SFTP、监控或任务；平台不向操作者返回私钥或导入口令。单机优先，凭据、类型及历史版本支持 PostgreSQL 单活 HA。竞品与完整范围仍为 [JumpServer 企业版](https://www.jumpserver.org/enterprise.html)，见 [PLAN](./PLAN.md)。

## 导入与编辑

在资产表单选择「SSH 私钥」，粘贴 PEM/OpenSSH 私钥；加密密钥填写正确的导入口令。支持 RSA 2048–8192 位、ECDSA P-256/P-384/P-521 和 Ed25519，不接受 DSA、SSH 证书或公钥文本。导入使用 `x/crypto/ssh` 解析，OpenSSH bcrypt 参数限制最多 64 轮；私钥解析上限 64 KiB，整个 JSON 请求也限 64 KiB。超限、错误口令或不支持格式会被拒绝，不返回解析中的密钥材料。

服务端将密钥规范化为无口令 OpenSSH PEM，再用 Vault key 的 AES-GCM 加密；**不保存导入口令**。加密附加数据绑定资产/历史版本及凭据类型。API 仅返回 `credential_type` 和 `key_fingerprint` 公钥指纹，SSH 主机指纹仍使用独立的 `host_key_fingerprint`，每跳都必须校验。

编辑时私钥和口令字段为空，表示保留当前密钥。口令不能单独替换；替换密钥时必须重新提交完整密钥与其口令。切换密码/私钥类型需提供新类型的完整凭据，不能混合两个类型。保存或关闭表单后清空输入字段，凭据不写入浏览器持久化存储。

## 历史、恢复与轮换

历史最多保留十个加密版本；备份元数据包含凭据类型和公钥指纹。私钥恢复先通过所选路由验证目标主机指纹及候选私钥登录，再原子切换保管库凭据；验证期间记录变化则拒绝提交。失败保留原凭据。平台不会修改远端 `authorized_keys`，失效或已撤销的旧私钥不能通过恢复重新启用。

七天密码轮换只对密码资产调度；私钥资产不显示密码轮换操作；可手动安装/轮换密钥，或另行启用七天密钥轮换计划。恢复密码备份时可用当前私钥登录执行 `chpasswd`，仍需原有 root 或免交互 sudo 权限。待恢复的新密码先验证后提交；失败时可用旧私钥回退，重启/接管后继续恢复。历史密码通过 SSH stdin 传送，不能包含 CR/LF/NUL，最长 4096 字节；自动轮换仍生成符合原强密码规则的新密码。

## 验证与边界

Testify 用例覆盖加密/明文格式、口令与算法策略、KDF 工作量限制、加密落盘、类型混用拒绝、仅元数据编辑、逐跳私钥认证、指标/命令/PTY/SFTP、备份验证与原子恢复、私钥认证下密码恢复及 HA 接管。Playwright 从 CLI 生成公开合成夹具密钥，经中英表单导入后验证网关、监控、Web SSH、CLI 和备份恢复。入口见 [TESTING](./TESTING.md)。

当前尚不包含 SSH CA/证书、硬件签名器、外部 Vault/KMS 或操作者个人公钥登录入口。这里管理的是纳管主机凭据，不代表上述功能已经完成。合成夹具密钥仅用于本机测试，不能安装到真实主机。
