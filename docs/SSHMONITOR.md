# SSH 主机监控

> 中文 | [English](./SSHMONITOR.en.md)

SSH 密钥安装、验证后轮换、显式启用的七天计划及持久化阶段恢复见 [SSH 密钥轮换](./SSH-KEY-ROTATION.md)。

目标资产与网关现支持导入 SSH 私钥：输入只写、保管库加密、公钥指纹及验证后恢复历史版本。密码轮换仍按密码凭据调度，详见 [SSH 私钥](./SSHKEYS.md)。

SSH 网关现支持最多三跳，监控、Web SSH、CLI、SFTP、任务和改密共用逐跳指纹校验连接。配置与加密凭据支持单机及 PostgreSQL 单活 HA，详见 [SSH 网关](./GATEWAYS.md)。完整企业版对齐仍在推进。

`assets.view_all` 可授予全局只读清单和监控，不提供 SSH 连接；探测与资产管理使用独立系统权限。详见 [RBAC.md](./RBAC.md)。

当前监控面板针对登记的 Linux SSH 主机，展示连接状态与延迟、CPU 使用率与核数、内存使用量、根文件系统磁盘用量，以及网络收发速率。每台资产占一行；监控列左侧放 CPU/内存指标条，右侧放上下行速率/磁盘指标条，布局与参考截图一致。

## 采集方式

- 服务端使用资产中加密保存的 SSH 凭据连接主机；必须匹配登记时固定的 SHA256 主机密钥指纹。浏览器不会接触 SSH 密码。
- CPU 通过 `/proc/stat` 两次采样的一秒差值计算；内存读取 `/proc/meminfo`；网络读取 `/proc/net/dev` 并忽略 loopback；磁盘展示 `/` 文件系统的总量和使用量。
- 每次 SSH 探测计算连接延迟。网络速率由服务端比较相邻两次字节计数得出；初次采集、主机重启或计数器回退时速率为零。
- 默认每 60 秒采集一次。可设置 `JMS_MONITOR_INTERVAL`，最小 15 秒。资产页每 15 秒刷新显示，因此读数更新速度由采集间隔决定。
- 尚未采集的主机显示“待检查”；探测失败显示离线与本地化错误提示。探测最多并发 8 台主机。

## 授权

- 管理员可添加资产、手动探测、编辑与删除资产。
- 操作员只能看到其有效用户/用户组—资产/节点—SSH 账号—动作—时间授权覆盖的资产；节点授权对当前节点及其所有后代资产生效。`view` 可查看资产和监控数据，`connect` 会同时包含 `view` 并允许新建 Web SSH 会话。
- 用户、用户组、资产和节点授权可在系统设置的访问控制页维护。操作员只会看到已授权资产所在的节点链及祖先，不会看到无关节点。管理员可查看全部会话；操作员只能查看、结束和回放自己的会话。

## 当前边界

- 监控仅支持提供常用 Linux `/proc` 与 POSIX 命令工具的主机；不安装 Agent。
- 最新快照保留在内存，重启后重新采集；新增[加密分钟历史与 Web/CLI 曲线查询](./MONITOR-HISTORY.md)，最多七天，保留缺失值并沿用当前资产授权。[监控告警](./MONITOR-ALERTS.md)支持阈值、离线、无数据规则及持久化事件、确认、恢复和通知。
- 单机模式是默认部署。集群模式采用单活热备，只有持锁节点执行采集；故障切换后新节点会恢复采集，但内存中的最新快照不会跨节点保留。
