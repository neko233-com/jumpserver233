# 性能与打包基线

[English](./PERFORMANCE.en.md) | [文档索引](./README.md)

2026-10-17 会话协作切片：邀请面板约 4.83 kB、参与页面约 5.13 kB、活动列表约 2.11 kB，均按需加载。主入口 448,885 字节；含共享静态依赖的初始脚本 466,229 字节，gzip 150,880 字节；全部 JS 1,218,401 字节，既有预算通过。Windows stripped 服务端 39,199,744 字节，CLI 12,229,120 字节。每活动终端最多缓存 64 KiB 输出尾部，参与者队列有界；没有复制整份录像。

2026-10-17 会话安全切片：系统设置模块按需加载约 3.16 kB，主入口 444.38 kB，既有体积预算通过。Windows stripped 程序为 38,993,408 字节，比上次基线增加约 0.36%；本地生产 API 镜像为 23,501,151 字节。

1280×720 合成静态帧的水印层基准：重新渲染约 7.17 ms / 8.34 MB 临时分配；同序号缓存约 14.5 ns、零分配。该基准不含网络、远端桌面或连接器开销，不代表端到端帧延迟。

生产 Docker 上下文排除 Go 测试文件、协议夹具、Playwright 用例和文档，修改测试不会使生产源码复制层失效。CI 的测试仍使用完整检出，不受 `.dockerignore` 影响。新增实时监看按需加载，主入口仍受既有体积预算检查。

2026-10-16 本机生产构建结果：

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 主入口 JavaScript | 628.26 kB | 442.11 kB（减少约 29.6%） |
| 主入口 gzip | 200.51 kB | 142.26 kB（减少约 29.1%） |
| Windows 服务程序 | 51,472,896 字节 | 38,855,168 字节（减少约 24.5%） |

登录页独立懒加载；Motion 使用 `LazyMotion` + `domAnimation` 和精简 `m`，保留现有动画。已认证控制台不下载登录动画代码。所有路由 JavaScript 合计 1,187,416 字节；计入共享依赖后的初始脚本为 459,455 字节，gzip 合计 148,477 字节。不能把主入口大小当成全部下载体积。

`pnpm build` 保留严格类型检查，TypeScript 与 E2E 分别使用 `node_modules/.cache/` 下的增量缓存。本机 Vite 打包约 160–253 ms，完整命令另含类型检查和预算验证；这些是本机热缓存观察值，不代表冷构建或其他机器。

构建自动运行 `scripts/check-web-bundle.mjs`，限制单 JS/初始静态依赖合计各 500,000 字节、全部 JS 1,500,000 字节，并检查登录路由保持懒加载。默认 Vite 大包警告没有调高。终端、协议对话框和管理页面继续按需加载。

`make build` 同时生成服务端、平台 CLI 和网页；Go 交付程序使用 `-trimpath -ldflags="-s -w"`。原生 Linux 组件的源码摘要未变时，生成器直接复用已验证产物。Go/pnpm/TypeScript 缓存在 [Docker 验证](./DOCKER-QA.md) 中也会复用。未以不同缓存状态的两次构建宣称速度提升。

`.gitignore` 排除依赖、构建/测试结果、增量缓存、环境文件、运行数据和本地工具文件；源码、锁文件、必要驱动源码及许可继续纳入版本管理。运行日志、私钥、Vault 与 QA 数据不会进入提交。
