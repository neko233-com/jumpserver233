# 产品定位与当前交付范围

> 中文 | [English](./PRODUCT-SCOPE.en.md)

2026-10-21 用户修正目标：**面向中小公司的独立 mini SSH 跳板机，单机部署，少依赖，好用、好维护、安全高效。** 本文覆盖此前“完整复刻企业版”和 42 组全部补齐的范围解释。JumpServer 企业版只作为交互和安全能力参考，竞品有某项功能不构成实现需求。

## 当前必须做好

1. **连接简单**：主机列表、分组、搜索、收藏、多账号；Web SSH、平台身份 CLI/Agent CLI 和 SFTP。平台保管目标凭据，操作者不必获取密码。
2. **权限和审计可靠**：用户/角色/资产授权、在线撤销、主机密钥校验、会话录像、文件及命令留痕；敏感命令拒绝、脱敏和人工复核；受控执行通道落实精确/子树/正则目录规则。
3. **日常运维方便**：CPU、内存、磁盘、网络、在线状态、必要历史及告警；SSH 密码/密钥七天轮换、检测、重试和恢复。原生主机 Agent、插件检测/安装按需启用。
4. **更新和数据可恢复**：检查更新、受控安装/回滚、幂等导出/导入，升级不丢资产、凭据、授权和审计。明确支持的版本范围，不以未经验证的兼容承诺代替恢复演练。
5. **部署与操作轻量**：一个 Go 服务、静态网页、一个持久化数据目录；运行不要求 Node、Redis、PostgreSQL、Docker、云账号、第三方身份平台或外部 AI。已有本地加密文件继续兼容，本批执行历史的内置 SQLite 不新增常驻服务。
6. **交付可维护**：中文/英文介绍、界面及文档，自动语言识别；发布时生成 changelog；构建、体积、性能、`.gitignore` 和幂等 QA 清理一起收尾。

## 当前不扩展

云同步及 23 厂商对齐、更多数据库协议、应用市场/虚拟应用、人脸识别、复杂企业身份集成、BI/PDF/邮件报表、多活集群和强制 Ansible/Docker 运行时均不作为本次目标。保留已交付能力和用户数据，撤回本批尚未发布且与 mini 无关的扩展；不再为对标补齐差距。以后只有明确使用需求才进入实现。

单机是默认验收环境。已有 PostgreSQL 主备能力属于可选历史扩展，不要求单机用户安装。默认前端只打包 mini SSH 所需页面；云同步、AI、复杂企业身份、数据库审计和外部录像存储等 17 个页面退出产品路由与构建图。源码、后端兼容接口和已有数据保留。低频本地控制项收进“更多功能”；功能可见性不代替后端权限控制。

## 进度和验证

当前主清单采用 [PROGRESS 的 S01–S12](./PROGRESS.md)，共 **12 项**。旧主目标为 42 组，本次因用户明确收缩产品范围改为 12 项；旧 E01–E42 保留作历史研究，不计入当前目标剩余工作，也不把范围变化算作新增完成。

原 SSH 基线为 **9/12（75%）**；本批统一验证及交付后为 **12/12（100%），+3**。范围调整本身不计新增完成。实际源码、用例结果、跳过项及部署边界见 [mini 验收报告](./MINI-ACCEPTANCE.md)。

先完成 mini 稳定版这一批必要实现，再统一运行 Go/Testify、相关 race、生产构建、中英浏览器和隔离 Docker 验证。验证幂等、重启、撤权、升级/恢复以及性能和体积；保留紧凑报告与必要截图，重复清理本次自有资源。不再等待 42 组企业功能，也不逐个小功能反复跑完整套件。当前不部署内网；满足稳定版门槛后再发布一次。
