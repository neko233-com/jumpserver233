## 交互约定

- 侧栏搜索仅查页面；顶部快捷搜索查页面和当前组织 API 返回的授权资产。选择主机进入其筛选结果，不自动创建远程会话。搜索主机数据在关闭弹窗时中止。
- 节点/分组可折叠；在线/离线/未知是服务器返回状态。没有数据时不生成健康值。匹配不到资产与尚未创建资产分别提示。
- 更改表格密度只保存本机外观偏好。修改 SSH 字号或窗口大小不会新建会话。终端聚焦时 Esc 传给远端，关闭按钮结束会话。
- 文件跳转使用服务器既有工作目录边界；客户端不扩大可访问目录。文件搜索只筛选当前目录。传输继续走原审批、一次性会话和审计。
- 资产草稿按 Esc 或点遮罩时确认丢弃；明确点“取消”放弃草稿。保存中阻止遮罩/Esc 关闭。秘密不写入本地偏好或报告。
- 全局弹窗约束 Tab，关闭后恢复焦点；标签页支持左右方向键及 Home/End。加载骨架、空态、错误和重试均可读。
